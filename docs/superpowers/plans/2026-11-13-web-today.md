# Web UI: Today (≥1024px) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tighten the shared header and lay out Today's board column cleanly at ≥1024px.

**Architecture:** Add `lg:` Tailwind classes to `Hero.svelte` and the Today page. A `large` prop
on `CardBoard` and `BingoSquare` lets Today's board panel, which renders only at ≥1024px, use the
existing `lg` ring size.

**Tech Stack:** SvelteKit 2 / Svelte 5, Tailwind v4, Playwright (desktop project, 1280px).

**Spec:** `docs/superpowers/specs/2026-11-13-web-today-design.md`

## Global Constraints

- Only `lg:` (≥1024px) changes. Phones and 768–1023px are unchanged: the existing phone and tablet
  Playwright projects must pass with no edits to their expectations.
- Title: 40px at ≥1024px.
- No horizontal scroll at 1024px or 1440px.
- Never run `npm run dev`. Verify with Playwright and the `e2e-local` preview.

## Review Focus

1. **Today with no card** ("Build one" in the side column): the header still matches the content
   width, and the column has no empty points row.
2. **A recap banner above Heads up:** the board lines up with the first left card, whatever it is.
3. **Other pages' headers** (Card, Groups, Me) at 1280px: a 40px title and the same width as their
   content panels.
4. **A long greeting** (a long display name): the title wraps instead of overflowing.
5. **The 5×5 board on Today** with large icons: no horizontal scroll at 1024px.
